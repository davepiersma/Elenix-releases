# Elenix releases

Elenix is a taskbar for Windows 11, made by Vienix.

This repository only holds the release files. The source code is private.

## Install

Download `Elenix-Setup-<version>.exe` from the latest release and run it. It installs for your user account and needs no admin rights.

The file is not signed yet, so Windows SmartScreen may warn. Choose "More info" and then "Run anyway".

## Updates

Elenix checks this repository for a new release about once a day. You can turn that off in Settings, under About.

Each release lists the SHA-256 of its setup file. Elenix checks that hash before it installs an update.
